# Sulaf — arab oshxonasi landing sahifasi

Arab taomlari restorani **Sulaf** (سُلاف) uchun liquid glass uslubidagi landing sahifa.

## Ichida nimalar bor

- `index.html` — sahifaning o‘zi (intro animatsiyasi, menyu, bron formasi)
- `worker.js` — bron formasini Telegram botga ulaydigan Cloudflare Worker
- `img/` — taom rasmlari va asl menyu

## Kompyuterda ochish

```powershell
python -m http.server 5173
```

So‘ng brauzerda `http://localhost:5173` manzilini oching.
